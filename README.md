# DuaOnDevice

**A NivareQ™ project**  
**Version 1.0.0 — Initial Public Baseline**

> **Authentic Duas, available fully offline and on-device — with verifiable sources.**

DuaOnDevice is a provenance-first local Dua reference app. It ships a curated canonical collection of **199 records: 74 Quran, 122 Prophetic Sunnah, and 3 Companion/Athar** entries, with traceable source references for every canonical record.

**Companion app:** [AyahOnDevice](https://github.com/NivareQ/AyahOnDevice) — NivareQ's local Quran Ayah identification and reader project.

## Source transparency
Every canonical record includes a source citation and source link. Arabic/source provenance is treated as authoritative; English and Bengali transliterations and meanings are clearly separated reading aids. Where a Sunnah/Athar record has a reported grade, DuaOnDevice preserves that grading rather than silently upgrading it. That means the collection can include transparently labeled weak-status reports where they were intentionally retained.

## Highlights
- 199 canonical source-traceable Dua records;
- Quran, Prophetic Sunnah, and Companion/Athar provenance kept distinct;
- Uthmani and IndoPak Quran display where applicable;
- English and বাংলা transliteration and meaning aids;
- bilingual deterministic search and source/context matching;
- Saved items with personal titles and notes;
- user-created **My Duas** kept separate from the canonical corpus;
- versioned personal backup/restore;
- nine themes and installable PWA behavior;
- fully local canonical data and search after the app shell is cached.

## Privacy and religious-text integrity
Canonical Arabic/source records are bundled with the app and are not generated by AI. Personal Saved notes, My Duas, display preferences, and related data stay in local browser storage unless you explicitly export a backup.

## Offline use
The canonical corpus is bundled with the application. Once the app shell has been cached by the browser/PWA, normal v1.0 browsing, deterministic search, Saved data, and My Duas work without a network connection.

## Deploy
This repository is a deployable static app; no application build step is required. Serve the repository root over HTTPS.

The accepted application itself intentionally carries `noindex`/`robots.txt` restrictions. Public discovery should therefore come through the NivareQ website and repository unless that policy is deliberately changed in a later bounded release.
