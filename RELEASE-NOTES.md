# DuaOnDevice v1.0.0 — Initial Public Baseline

DuaOnDevice v1.0.0 is the initial public-source baseline for the provenance-first Dua reference app.

## Included
- 199 canonical records: 74 Quran, 122 Prophetic Sunnah, 3 Companion/Athar;
- source citation and verification link for every canonical record;
- preserved source grading where applicable;
- Uthmani/IndoPak Quran display where applicable;
- English and Bengali transliteration/meaning aids;
- deterministic bilingual search;
- Saved notes, My Duas, backup/restore, and nine themes;
- installable/offline-capable static PWA.

## Religious-text integrity
Canonical Arabic/source data is curated and bundled. Search retrieves records; it does not generate religious text.

## Smart Search
Not present in v1.0.0. The first Smart Search release is v1.1.0.
